planningResults.json — normalized JSON fixture containing 154 planning steps across 39 containers, 6 operators, and 5 operation types (Putaway, Premarshal ahead of retrieval, Digout to clear an overstow, Outbound staging and truck loading, Discharge from vessel). Each step has a unified schema with container_id, operation, activity_status, step_status, planning_score, step_number, move_method, operator, origin (bay/row/tier/lat/lng), destination (bay/row/tier/lat/lng), estimated_start, estimated_end, actual_start, actual_end. It also includes pre-computed lookup objects: containers, operators, and operation_summary.
planningData.ts — TypeScript module that imports the JSON and exports typed accessors. Key exports:
allSteps: PlanningStep[] — flat array of every step
containers — record keyed by container_id
operators — record keyed by operator name
operationSummary — record keyed by operation type
stepsForContainer(id) — steps for one container, sorted by step_number
stepsForOperator(name) — steps for one operator, sorted by estimated_start
stepsByOperation(type) — filter by operation type
stepsByStatus(status) — filter by Planned / Completed / Blocked
geoSteps() — only steps with lat/lng coordinates
stepsByBay() — Map keyed by bay number
containerIds() — sorted list of all container IDs
operatorNames() — sorted list of all operator names
dashboardCounts() — returns { totalContainers, totalSteps, totalOperators, planned, completed, blocked }
